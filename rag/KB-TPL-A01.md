# KB-TPL-A01｜積塵與鳥糞污染造成全場發電量緩降：清洗週期最佳化

- 故障分類：A 外部環境與資源

## 一句話結論

清洗不是越勤越好，而是「損失電費 = 清洗成本」時才洗；用降雨前後 PR 跳升量化積塵損失，即可算出最適清洗週期。

## SCQA

- **S 情境**：案場位於旱季長或鄰近工業、農業粉塵源之區域。
- **C 衝突**：PR 在旱季逐週下滑，降雨或清洗後跳升；清洗費用固定支出但效益不明。
- **Q 問題**：積塵損失多少？應多久洗一次？
- **A 答案**：以污染比 (Soiling Ratio) 追蹤每日損失率，當累積損失電費超過單次清洗成本時觸發清洗。

## 關鍵數據

- 量化指標：Soiling Ratio（或降雨前後 PR 差）
- 決策法則：損失 ≥ 清洗成本（觸發清洗）
- 特殊污染：鳥糞 = 熱斑（需立即處理）

## 根因

表面污染物累積降低入射光，損失隨時間遞增；降雨自然清洗不足時需人工介入。

## 假說檢定（MECE）

| 假說 | 檢定方法 | 證據 | 判定 |
|---|---|---|---|
| 均勻粉塵 | PR 緩降且降雨後回升 | 符合則確認 | 待驗 |
| 鳥糞點狀污染 | IR 熱點 + 目視 | 點狀熱斑 | 待驗 |
| 組件下緣積泥 | 目視下緣 | 低傾角常見 | 待驗 |
| 組件劣化（非污染） | 清洗後是否回升 | 不回升則改查劣化 | 待驗 |

## 8D 摘要

- **D0 緊急應變**：一般積塵無安全風險；鳥糞造成熱斑者轉入熱斑處置流程。
- **D1 成立團隊**：R：維運工程師（數據追蹤）｜C：清洗承攬商｜A：維運主管（預算）。
- **D2 問題描述**：以溫度修正 PR 計算每日污染損失率，並標記降雨、清洗事件。
- **D3 暫時圍堵**：高污染區（下風處、鳥害區）先局部清洗。
- **D4 根因分析**：MECE：均勻粉塵（全場緩降）、鳥糞（點狀熱斑）、下緣積泥（低傾角排水不良）、青苔 / 植被遮蔽。
- **D5 永久對策**：建立經濟清洗觸發模型；鳥害區加裝驅鳥設施；低傾角下緣積泥考慮調整清洗方式。
- **D6 實施驗證**：比對模型觸發清洗與固定週期清洗之年度淨效益。
- **D7 防止再發**：清洗觸發規則寫入 SOP；每年依實際數據重新校正。
- **D8 結案表彰**：以年度回收電量與節省清洗費雙向呈現效益。

## 對策

- [立即] 污染損失每日追蹤｜成本 低｜決策有據
- [首選] 經濟觸發式清洗｜成本 依次數｜最大化淨效益
- [視情況] 驅鳥設施｜成本 低~中｜減少點狀熱斑

## 現場檢查清單

1. 標記降雨與清洗事件於 PR 趨勢圖
2. 計算單次清洗成本與每日損失電費
3. 清洗後務必驗證 PR 回升
4. 清洗後不回升 → 轉查組件劣化
5. 鳥糞熱點轉熱斑流程

## Lesson Learned

- **L-A01-1 清洗是經濟決策不是例行公事**：固定週期清洗常在雨季浪費、旱季不足。 → 行動：以「累積損失 ≥ 清洗成本」觸發。
- **L-A01-2 清洗也是診斷工具**：清洗後 PR 不回升，代表問題不在表面。 → 行動：清洗前後量測納入標準流程。
