# KB-TPL-C02｜雨後與清晨絕緣阻抗低（Riso）導致逆變器無法併網

- 類型：產業典型知識卡（教學範本，非實際案場數據）
- 故障分類：C 直流傳輸線路
- 案場：示意案場（教學範本）｜通用｜高濕 / 多雨
- 設備 / 失效模式：直流電纜 / 組件 / 匯流箱｜濕氣造成對地絕緣下降，逆變器開機自檢失敗
- 風險：中｜損失型態：晨間發電損失
- 現象關鍵字：清晨逆變器延遲併網、雨後絕緣阻抗告警、中午乾燥後自行恢復、接地故障告警、Riso 低
- 標籤：絕緣阻抗、Riso、接地故障、Ground Fault、跳脫、晨間、雨後、電纜破皮、絕緣測試
- 簡報：https://davidyeh51.github.io/pv-8d-management-platform/deck.html?id=KB-TPL-C02

## 一句話結論

「雨後早上跳、中午自己好」的絕緣告警不是誤報，而是某處絕緣已劣化的早期訊號；以分段絕緣測試鎖定組串，修復破皮電纜或進水接頭即可根除。

## SCQA

- **S 情境**：案場在雨季頻繁出現絕緣阻抗告警。
- **C 衝突**：逆變器清晨開機自檢失敗、延後數小時併網，中午乾燥後自動恢復，常被當成誤報忽略。
- **Q 問題**：是哪一段絕緣劣化？要不要調低門檻？
- **A 答案**：不調門檻；於潮濕時段執行逐串絕緣測試，鎖定破皮電纜 / 進水連接器 / 組件邊框後修復。

## 關鍵數據

- 時間指紋：雨後 + 清晨（乾燥後恢復）
- 定位方法：分段絕緣測試（逆變器 → MPPT → 組串）
- 錯誤做法：調低門檻（掩蓋漏電與觸電風險）

## 根因

直流側某處絕緣層破損或密封失效，濕氣形成對地漏電路徑，使逆變器開機前絕緣自檢低於門檻。

## 假說檢定（MECE）

| 假說 | 檢定方法 | 證據 | 判定 |
|---|---|---|---|
| 電纜破皮對地 | 逐串絕緣測試 | 特定組串絕緣值低 | 待驗 |
| 連接器 / 接線盒進水 | 目視 + 拆解 | 內部積水鏽蝕 | 待驗 |
| 組件邊框 / 背板破損 | 目視與絕緣測試 | 單片組件對地低 | 待驗 |
| 逆變器量測誤差 | 外部儀表比對 | 外部量測同樣偏低則排除 | 待驗 |

## 8D 摘要

- **D0 緊急應變**：絕緣劣化有觸電與起火風險：量測前斷開直流並放電，穿戴絕緣防護；禁止調低保護門檻。
- **D1 成立團隊**：R：維運工程師（絕緣測試）｜C：逆變器原廠｜A：維運主管。
- **D2 問題描述**：從 SCADA 調出告警時間分布（與降雨、露點、時段比對）與受影響逆變器。
- **D3 暫時圍堵**：於潮濕時段（清晨或雨後）進場測試，以拆分 MPPT / 組串方式逐段縮小範圍。
- **D4 根因分析**：MECE：電纜破皮（動物咬、摩擦、施工損傷）、連接器進水、組件邊框/背板破損、匯流箱密封不良。
- **D5 永久對策**：更換破損電纜段、進水連接器或組件；電纜改走線槽並加防護。
- **D6 實施驗證**：連續一個雨季無絕緣告警，晨間併網時間恢復正常。
- **D7 防止再發**：SOP：絕緣告警不得以「自行恢復」結案；巡檢加入線槽、紮線與防鼠檢查。
- **D8 結案表彰**：以晨間延遲併網時數 × 日射估算損失，納入維運 KPI。

## 對策

- [立即] 潮濕時段分段絕緣測試定位｜成本 低｜精準鎖定故障段
- [首選] 更換破損電纜 / 連接器｜成本 低~中｜根除漏電路徑
- [制度化] 走線防護與防鼠改善｜成本 中｜防止再發

## 現場檢查清單

1. 比對告警時間與降雨、露點
2. 在潮濕時段測試（乾燥時測不到）
3. 斷電放電後再量測
4. 由大到小逐段拆分定位
5. 嚴禁調低保護門檻

## Lesson Learned

- **L-C02-1 會自己恢復的告警最危險**：間歇性絕緣告警代表劣化已發生，只是環境條件未持續觸發。 → 行動：設定「同一逆變器 30 天內 ≥3 次絕緣告警」自動開立 8D。
- **L-C02-2 在故障會出現的條件下測試**：乾燥中午測試常量不到問題。 → 行動：絕緣測試安排在清晨或雨後。
