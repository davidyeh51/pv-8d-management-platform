# KB-TPL-D01｜逆變器過溫降額：散熱風扇與濾網堵塞

- 類型：產業典型知識卡（教學範本，非實際案場數據）
- 故障分類：D 逆變轉換設備
- 案場：示意案場（教學範本）｜通用｜屋頂 / 機房 / 貨櫃
- 設備 / 失效模式：逆變器｜散熱不良觸發溫度降額保護
- 風險：中｜損失型態：夏季午間發電損失
- 現象關鍵字：夏季中午功率平頂但低於額定、逆變器內部溫度高、降額告警、同型號機台出力不一致、風扇異音或停轉
- 標籤：逆變器、過溫、降額、Derating、風扇、濾網、散熱、Clipping、機房通風
- 簡報：https://davidyeh51.github.io/pv-8d-management-platform/deck.html?id=KB-TPL-D01

## 一句話結論

夏季午間「平頂但沒到額定」通常不是容配比問題，而是逆變器在熱降額；清濾網、換風扇、改善通風是最高 CP 值的對策。

## SCQA

- **S 情境**：夏季高溫，逆變器安裝於通風不良處或運轉多年。
- **C 衝突**：午間功率出現平頂，但峰值低於額定，與同型號機台相比明顯偏低。
- **Q 問題**：是削峰 (Clipping) 還是過溫降額？
- **A 答案**：比對逆變器內部溫度與功率時序：溫度達門檻即降額，確診過溫；清潔濾網與更換風扇後恢復。

## 關鍵數據

- 判別關鍵：平頂高度（額定 = 削峰；低於額定 = 降額）
- 必看數據：內部溫度（與功率時序疊圖）
- 對策成本：低（清潔 / 換風扇 / 通風）

## 根因

逆變器散熱能力下降，內部溫度達保護門檻後自動降低輸出功率。

## 假說檢定（MECE）

| 假說 | 檢定方法 | 證據 | 判定 |
|---|---|---|---|
| 容配比過高造成 Clipping | 平頂高度是否等於額定 | 低於額定則排除 | 待驗 |
| 濾網 / 鰭片堵塞 | 目視與清潔前後比對 | 清潔後溫度下降 | 待驗 |
| 風扇故障 | 運轉檢查 | 停轉或轉速低 | 待驗 |
| 安裝環境過熱 | 環境溫度量測 | 日曬或密閉空間 | 待驗 |

## 8D 摘要

- **D0 緊急應變**：過溫本身為保護動作；若伴隨焦味、冒煙或風扇卡死，應停機檢查。
- **D1 成立團隊**：R：維運工程師｜C：逆變器原廠｜A：維運主管。
- **D2 問題描述**：從 SCADA 調出同型號機台午間功率與內部溫度，計算降額時數與損失。
- **D3 暫時圍堵**：清潔濾網與散熱鰭片、確認風扇運轉。
- **D4 根因分析**：MECE：濾網 / 鰭片堵塞、風扇故障、安裝位置日曬或通風不足、機房空調失效、逆變器容量不足（Clipping）。
- **D5 永久對策**：更換故障風扇；加裝遮陽棚或改善機房通風；必要時調整安裝位置。
- **D6 實施驗證**：下一個高溫日比對降額時數與峰值功率。
- **D7 防止再發**：預防保養表加入濾網清潔週期與風扇運轉檢查；設定內部溫度預警。
- **D8 結案表彰**：以挽回午間電量估算效益；統計同型號風扇壽命作為備品規劃。

## 對策

- [立即] 清潔濾網與鰭片｜成本 極低｜立即降溫
- [首選] 更換風扇｜成本 低｜恢復散熱
- [視情況] 遮陽 / 改善通風｜成本 中｜根本改善

## 現場檢查清單

1. 功率與內部溫度疊圖
2. 確認平頂高度 vs 額定
3. 同型號機台橫向比較
4. 檢查風扇與濾網
5. 量測安裝環境溫度

## Lesson Learned

- **L-D01-1 平頂不一定是 Clipping**：低於額定的平頂多為熱降額。 → 行動：判讀平頂時同時看內部溫度。
- **L-D01-2 同型號橫向比較最快**：同條件下出力最差的機台就是調查起點。 → 行動：SCADA 建立同型號機台出力排名。
